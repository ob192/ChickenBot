# ChickenBot

A Telegram bot built with [aiogram](https://docs.aiogram.dev/).

## Setup

1. Create a virtual environment and install dependencies:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Copy `.env.example` to `.env` and fill in your bot token from [@BotFather](https://t.me/BotFather):

   ```bash
   cp .env.example .env
   ```

3. Run the bot:

   ```bash
   python main.py
   ```
